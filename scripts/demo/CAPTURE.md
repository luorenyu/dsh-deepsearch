# 0.1.17 isolated capture notes

Run from the repository root with Node 22+, npm, and agent-browser (Chromium installed):

```sh
node --test scripts/demo/*.test.mjs
node scripts/capture-demo.mjs
```

The runner installs pinned React/ReactDOM 18.3.1 into a fresh OS temporary directory, starts an ephemeral loopback-only allowlisted server, and uses a fresh named headless agent-browser session. It clears inherited AGENT_BROWSER_* variables. Browser, server, and temporary dependencies are closed/removed in finally. No real DSH page, existing browser profile, CDP, accounts, conversation storage, native navigation, or host shortcut configuration is used.

The current repository client.js is served byte-for-byte. The real plugin renders the panel, CSS, settings, history tabs, local history store, debounce, replay, archive checkbox, project action, unread state/menu/leading-slot component, and shortcut takeover controller. The minimal host adapters, API responses, Chinese content, sidebar layout, StateDot appearance, theme tokens, New Session callback, and public-shortcut service are mocked. The page-only Date.now clock is fixed to a fictional 2026-10-12 timestamp for history rendering; debounce timers remain real.

## Current capture behavior

- 01-search.png: explicitly unchecks the current default-enabled archive checkbox before showing four fictional matches.
- 02-projects.png: shows the real project New Session hint. Clicking invokes only the mock startSession callback and closes the overlay; it does not scope the search. Workspace filtering is independently exercised through the real selector (two matches).
- 03-archived.png: checks the archive control by its label, not by checkbox position; shows five matches with archive metadata.
- 04-glass.png through 07-unread-settings.png: real appearance and compact settings controls, with mocked background/theme and no replacement panel markup.
- 08-unread-menu.png: existing approved illustration is preserved byte-for-byte, never regenerated by this pipeline. Its unread-card.html and unread-scene.html sources are unchanged. It is illustration, not runtime evidence.
- component-unread-evidence.png: separate real plugin menu/leading-slot evidence on the isolated fictional host. Mark-read and mock mainView re-entry auto-read checks are also exercised.
- 09-history.png: history is cleared through real UI, then three fictional searches are recorded through the real one-second debounce. The default-history checkbox, selected history tab, persistence across reopen, and replay are verified.
- 10-settings.png: compact settings with the real CmdK switch enabled using an in-memory macOS desktop public-shortcut service. Capture then dispatches CmdK through this service, disables takeover, and verifies backup removal/restoration. This is not native host shortcut integration evidence.

Every runtime image uses the 1180×960 feature-card frame and visible isolated-demo disclosure. demo-evidence.json records source SHA-256/version, per-image SHA-256, rendered state, fictional API requests, and the real-vs-mock boundary. screenshots.json lists generated images plus the preserved approved illustration. Browser errors, version/state mismatches, unexpected native navigation, or an approved illustration hash change fail capture.
